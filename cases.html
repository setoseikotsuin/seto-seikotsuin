Sports Injury

スポーツに関するお悩み

競技復帰までの期間を逆算し、応急処置からフォーム改善まで一貫してサポートした症例です。

足関節捻挫（前距腓靭帯損傷）10代 男性 / サッカー部 → オスグッド・シュラッター病10代 男性 / バスケットボール部 → シンスプリント（脛骨過労性骨膜炎）20代 女性 / 市民ランナー → 上腕骨外側上顆炎（テニス肘）30代 女性 / テニススクール通い →

Traffic Accident

交通事故によるケガ

自賠責保険の適用により窓口負担0円で施術を受けられます。事故直後の対応から示談までサポートします。

頸椎捻挫（むち打ち症）30代 女性 / 会社員 → 腰部打撲・腰椎捻挫40代 男性 / 配送業 → 肩関節周囲の損傷20代 男性 / 自転車事故 →

Back & Lower Back

腰・背中に関するお悩み

腰痛の多くは腰以外に原因があります。股関節や胸椎の動き、腹圧まで含めて評価した症例です。

急性腰痛症（ぎっくり腰）40代 女性 / 事務職 → 慢性腰痛（反り腰を伴う）30代 女性 / デスクワーク → 坐骨神経痛（梨状筋症候群）40代 男性 / 営業職 → 腰部脊柱管狭窄症70代 男性 →

Leg & Knee

足・膝に関するお悩み

歩行パターンと筋力バランスを評価し、10年後も自分の足で歩ける身体づくりを目指した症例です。

変形性膝関節症60代 女性 / 主婦 → 鵞足炎40代 女性 / ウォーキング習慣あり → 足底腱膜炎50代 男性 / 立ち仕事 → 産後の股関節痛30代 女性 / 産後8ヶ月 →

Head, Neck & Shoulder

頭・首・肩に関するお悩み

デスクワークやスマートフォンによる負担を、姿勢と肩甲骨の動きから根本的に評価した症例です。

慢性肩こり30代 女性 / デスクワーク → ストレートネック20代 女性 / 美容師 → 肩関節周囲炎（四十肩・五十肩）50代 男性 / 自営業 → 緊張型頭痛30代 男性 / IT関連 → 寝違え（急性頸部痛）20代 女性 / 接客業 →
